# Antigravity-CN

Antigravity macOS 桌面版的社区中文化源码。此仓库不是 Google 官方项目，也不提供修改后的应用程序或官方界面包。

## 版本状态

| 版本 | 状态 |
| --- | --- |
| 2.26.0 | 组件源码、动态界面、权限卡片方案已在本机验证；可用本仓库流程离线重建。 |
| 2.27.0 | 2026-10-28 本机已安装；尚未取得该版本的原始 UI 包，组件覆盖和运行效果未验收。 |

构建器必须同时匹配应用版本和原始 UI 包的 SHA-256。遇到新版本或源码结构改变会停止替换，不会强行套用旧包。2.26.0 的覆盖数字不代表 2.27.0 已完成汉化，也不代表远程内容、系统原生菜单或未来文案全部中文。

## 源码结构

- src/component：从官方本机 UI 包提取展示文案，并按语法树位置生成本地中文组件包；保留功能属性及占位符。
- src/dictionaries：离线翻译结果与人工校订术语。
- src/dom：基于上游 MIT 项目的动态界面词库，保护用户消息、代码、输入框值和编辑器内容。
- src/permission：权限卡片的固定文案原位翻译；保留命令正文、选项值、草稿和选择状态。
- src/runtime：仅连接本机官方 Antigravity 调试端口，按版本及哈希校验后注入；没有自动重启、刷新或导航应用页面。
- scripts：读取本机官方 UI 包和构建中文包的工具。
- third_party/upstream：已固定的上游 MIT 源码与原始许可证。
- tests：无需启动 Antigravity 的权限翻译测试。

## 本机构建

需要 macOS、Node.js 22 或更新版本，以及自行合法取得的当前版本官方 UI main.js。应用运行时可选用只读捕获工具；它只请求本机的 main.js，不重启、不刷新、不导航，也不会点击任何权限按钮：

~~~sh
npm ci
npm run capture
npm run build -- inputs/2.27.0/main.js 2.27.0
npm test
~~~

如果当前没有运行中的 Antigravity 窗口，capture 会直接报错；它不会替你启动应用。2.26.0 可将已核实的官方 main.js 路径作为 build 的第一个参数。构建结果位于 build/版本号/，其中包含中文组件包、词库、哈希清单与运行模块。inputs/ 和 build/ 均不会提交到 Git。

当前版本的组件适配必须先检查 build 输出的 unmapped.json、coverage.json、排除项和 UI 结构，再在实际界面验收。若源码结构变化导致构建失败，应新增定点适配规则，不能绕过版本或哈希保护。

运行模块为 build/版本号/monitor.mjs 和 build/版本号/monitor-permission.mjs。请仅在对应版本完成验收后启用，并避免与同版本旧后台重复运行。它们不会自动重新加载已有项目；组件层替换只会在后续自然加载时生效。单独停用后台不会抹掉当前页面上已经显示的中文文字。

## 公开边界

仓库只发布汉化项目自身源码、词库、测试和上游许可允许再分发的源码。官方 main.js、修改后的 main.zh-CN.js、app.asar、应用备份、浏览器缓存、用户会话、命令正文及凭据均不上传。提交前请检查本地改动；不要使用全量目录复制来替代白名单。

上游来源与版本固定信息见 [来源说明](docs/PROVENANCE.md)。如需重新翻译新版本的候选文案，可选用 src/component/translate-local.swift 调用本机 macOS Translation 框架，再人工校订；不要把用户内容作为翻译输入。
